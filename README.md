# Fonxy Bot

a silly discord bot made for a specific discord server

## commands

- **`/help`** - shows help message
- **`/ping`** - check the bot's latency
- **`/github`** - get the link to the bot's GitHub repo

## easter eggs

say these in chat and the bot will reply:

- `meow` 🐱
- `woof` 🐶
